# shikaku-trainer（死角トレーニング）

サッカーの「死角」「首振り」「コースの切り方」を練習する、iPad（ジャイロ）向けの3Dトレーニングゲーム。将来はQuest 2（WebXR）にも対応予定。

## いま遊べるドリル

**ワンサイドカット（ディフェンス）**
- ボールが来る前に首を振って、危ない受け手を見つける
- そのパスコースを体で切りながら寄せる
- 反対側は味方に声で指示（「左いけ！」「右いけ！」）
- 終わると「コースを切る・首振り・声の指示・寄せ」の4項目を採点し、上から見たリプレイを表示

レベル1〜3で相手の判断の速さが変わります。

## 遊び方

`index.html` をHTTPSで開くだけ（GitHub Pages など）。iPadのSafariで「ジャイロで始める」を押し、モーションとマイクを許可してください。

- 左側を押してスティック移動、右側ドラッグで向きの微調整
- 声が使えない環境では画面下のボタンで指示できます

## 構成

`index.html` 1ファイルのみ（three.js r128 を cdnjs から読み込み）。
