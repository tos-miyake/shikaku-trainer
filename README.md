# shikaku-trainer（死角トレーニング）

サッカーの「死角」「首振り」「コースの切り方」を練習する、iPad（ジャイロ）向けの3Dトレーニングゲーム。将来はQuest 2（WebXR）にも対応予定。

## いま遊べるドリル

スタート画面でドリルとレベル（1〜3）を選びます。

**ワンサイドカット（守備・声の指示）**
- ボールが来る前に首を振って、危ない受け手を見つける
- そのパスコースを体で切りながら寄せる
- 反対側は味方に声で指示（「左いけ！」「右いけ！」）
- 採点：コースを切る・首振り・声の指示・寄せ

**マークを外さない（守備・首振り）**
- 前で相手3人がボールを回し、近くの「マーク」があなたの死角（背中側）に入ろうと動く
- マークを一定時間（レベル1:3秒〜レベル3:1.8秒）見ないと背後に走られて失敗。ボールを3.5秒見ないのも失敗
- マークより ゴール側・2〜3m に立って15秒守り切る
- 採点：マークの確認・ボールの確認・ゴール側に立つ・距離

**背後へ飛び出す（攻撃・DFの視線）**
- 背中側のDFは、ボールと「最後にあなたを見た場所」を交互に見る。見えていないあなたは追えない
- DFの肩の後ろ（ボールと反対側）に立ち、味方が足を振り上げた瞬間に裏へ走る
- 早すぎるとオフサイド、DFに見られて走るとついてこられる
- 採点：ボールと同時に見せない（DFから見た角度）・視線を盗む・飛び出しのタイミング・首振り

どのドリルも、終わると上から見たリプレイが出ます（DFの見ている範囲は赤い扇形）。

## 遊び方

`index.html` をHTTPSで開くだけ（GitHub Pages など）。iPadのSafariで「ジャイロで始める」を押し、モーションとマイクを許可してください。

- 左側を押してスティック移動、右側ドラッグで向きの微調整
- 声が使えない環境では画面下のボタンで指示できます
- マイクを使うのは「ワンサイドカット」だけです

## 構成

`index.html` 1ファイルのみ（three.js r128 を cdnjs から読み込み）。
