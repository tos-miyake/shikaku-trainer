# shikaku-trainer（死角トレーニング）

サッカーの「死角」「首振り」「コースの切り方」を練習する、iPad（ジャイロ）向けの3Dトレーニングゲーム。将来はQuest 2（WebXR）にも対応予定。

## いま遊べるドリル

**ワンサイドカット（ディフェンス）**
- ボールが来る前に首を振って、危ない受け手を見つける
- そのパスコースを体で切りながら寄せる
- 反対側は味方に声で指示（「左いけ！」「右いけ！」）
- 終わると「コースを切る・首振り・声の指示・寄せ」の4項目を採点し、上から見たリプレイを表示

レベル1〜3で相手の判断の速さが変わります。

## 遊び方

`index.html` をHTTPSで開くだけ（GitHub Pages など）。iPadのSafariで「ジャイロで始める」を押し、モーションとマイクを許可してください。

- 左側を押してスティック移動、右側ドラッグで向きの微調整
- 声が使えない環境では画面下のボタンで指示できます

### VRゴーグル（iPhoneをはめる簡易ゴーグル）

1. iPhoneを横向きにして「VRゴーグルで始める」を押し、モーションとマイクを許可
2. 画面が左右2つに分かれたらゴーグルにはめる
3. 声でメニュー操作：「スタート」「つぎ」「メニュー」「レベル1〜3」「正面」「ゴーグル終了」（ゴーグルのボタンを1回押すのも「決定」）
4. 前に進む：ゴーグルのボタンを押しっぱなし／足ぶみ（スタート画面で選ぶ）／Bluetoothコントローラーの左スティック

- プレイ中は右上の「ゴーグルモード」でいつでも切り替え。もどるときは「ゴーグル終了」と言うか、2本指でタップ
- 声で言う言葉は `index.html` の `VOICE` で変えられます
- コントローラー：左スティック＝移動、右スティック＝向き、A＝決定、LB/RB＝「左いけ」「右いけ」
- Safariのアドレスバーが邪魔なときは「ホーム画面に追加」から開くと全画面になります
